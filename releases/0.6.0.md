# 0.6.0 — Context selectiu i skills SEO/GEO

## Canvis

- `AGENTS.md` concentra l'entrada mínima; procediments, models i descoberta
  queden als documents pertinents. `CLAUDE.md` importa aquesta font única.
- Descripcions de skills més curtes; SEO i GEO són dues skills pròpies amb
  referències sota demanda i fonts oficials revisades el 2026-10-28.
- `docs/foundation/context-loading.md` documenta què pot descobrir cada motor
  i els límits de les mesures de context. No altera configuracions globals.
- `scripts/check-foundation.sh` unifica la verificació local i GitHub Actions;
  accepta `PYTHON` per seleccionar un intèrpret 3.10 o superior.
- El document de qualitat generat consulta el catàleg sense fixar un nombre de skills.

## Migració de 0.5.0

1. Revisa les instruccions locals abans de fusionar l'entrada compacta: conserva
   les normes pròpies del producte. No substitueixis el brief, notes ni pla.
2. Afegeix `.agents/skills/seo/` i `.agents/skills/geo/` i fusiona les seves entrades
   a `skills/catalog.json`. Actualitza les descripcions dels adaptadors si escau.
3. Incorpora el script comú, el canvi de text de `scripts/foundation.py` i les
   guies pertinents. Adapta la CI al servei del producte, preservant-ne les proves.
4. Executa `sh scripts/check-foundation.sh` amb Python compatible i les proves
   del producte. Registra la versió adoptada a `foundation.json`.

No canvia l'esquema del brief, la política de models ni les fonts vendored.
Els productes existents no necessiten regenerar els documents només per canviar
una frase del text de qualitat; actualitza'ls en el següent refresh justificat.
La plantilla continua `uninitialized`, sense dades d'un producte concret.
