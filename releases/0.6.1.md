# 0.6.1 — Base comuna per a Claude, Codex i Cursor

## Consolidació

- `feat/library-profile` ja forma part de main amb els perfils library i service.
- `feat/claude-cursor-engines` ja forma part de main amb configuracions natives,
  selecció de models i mínims per rol per a Claude, Codex i Cursor.
- S'incorpora `codex/lean-context-seo-geo`, amb l'entrada compacta, SEO/GEO i la
  verificació comuna de 0.6.0.
- README i `docs/foundation/engines.md` expliquen l'inici i la represa amb els
  tres motors. Les skills mantenen una sola font a `.agents/skills/`.
- Els noms natius passen a `foundation-light`, `foundation-standard` i
  `foundation-deep`, compatibles amb la convenció documentada de Cursor.
- Cursor deixa d'emetre el camp Markdown `effort`, absent del seu esquema
  documentat; policy i el manifest el conserven per als slugs Grok configurats.
- S'elimina el camp `orchestration` sense consumidor, que suggeria un principal
  Claude global. Cada motor manté el seu principal i tots els models existents.
- Tests addicionals cobreixen la selecció dels agents dels tres motors, el
  format natiu i la detecció de deriva i de definicions antigues duplicades.

## Migració de 0.6.0

1. Fusiona els canvis de `routing/policy.json` i `scripts/routing.py`, preservant
   els models propis que hagis validat.
2. Revisa la sortida dels tres `render-*`. Trasllada les personalitzacions dels
   fitxers `foundation_*.toml`/`foundation_*.md` als nous `foundation-*` i elimina
   només els fitxers antics substituïts. Actualitza invocacions que usin els noms vells.
3. Incorpora proves i guies, executa `sh scripts/check-foundation.sh` i comprova
   la descoberta en una sessió nova del motor escollit.

No cal regenerar el brief ni el pla. Les llicències i els fitxers vendored es
conserven intactes. Els tests són locals i no certifiquen l'accés del compte als models.
