# Fonts de tercers

Les fonts de `vendor/` són còpies de revisions concretes, sense modificacions del
contingut descarregat. Els SHA complets i les rutes originals són a
`skills/catalog.json`; les empremtes per fitxer són a `skills/lock.json`.
Els adaptadors de `.agents/skills/` són instruccions locals separades.

| Material | Font | Condicions conservades |
|---|---|---|
| Clean Code | [btseee/clean-code-skills](https://github.com/btseee/clean-code-skills) | MIT, `vendor/licenses/btseee--clean-code-skills/LICENSE` |
| Frontend Design i Webapp Testing | [anthropics/skills](https://github.com/anthropics/skills) | Apache 2.0, `LICENSE.txt` a cada skill |
| Web Design Guidelines | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) | README declara MIT; còpia a `vendor/licenses/vercel-labs--agent-skills/README.md`. Sense LICENSE separat en aquella revisió |
| Web Interface Guidelines | [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines) | MIT, `vendor/references/web-interface-guidelines/LICENSE` |
| UX Heuristics | [wondelai/skills](https://github.com/wondelai/skills) | MIT, `vendor/licenses/wondelai--skills/LICENSE` |
| Security Audit | [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) | MIT, `vendor/licenses/cloudflare--security-audit-skill/LICENSE` |
| Systematic Debugging i dues dependències | [obra/superpowers](https://github.com/obra/superpowers) | MIT, `vendor/licenses/obra--superpowers/LICENSE` |

Les atribucions i condicions originals es mantenen aplicables encara que el
repositori sigui privat. No s'ha assignat una llicència de codi obert al contingut
propi d'aquesta plantilla. Incorporar una font no implica aval dels seus autors.

Les skills opcionals del catàleg no formen part de les còpies incorporades.
