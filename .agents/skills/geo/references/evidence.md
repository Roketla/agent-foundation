# Contingut i evidència GEO

Revisat el 2026-10-28. Aquest és un mètode de treball local, no una fórmula de
rànquing documentada pels proveïdors.

## Preparar una font útil

Selecciona les preguntes reals del públic. Per a cada pregunta, identifica la
pàgina que pot respondre-la i què falta per fer-ho amb precisió. Prefereix
respostes directes, condicions explícites, unitats, dates pertinents i enllaços a
fonts originals quan sostinguin l'afirmació. No afegeixis cites decoratives.

Mantén coherència entre nom de marca, entitat, serveis, ubicacions i contacte.
Distingeix les dades del propietari del web de les d'un establiment llistat.
Mostra autors o responsables només quan siguin reals. No fabriquis experiència,
premis, adreces, comparatives ni opinions de tercers.

Taules i preguntes freqüents poden facilitar la lectura si el contingut ho
justifica; no són una garantia de citació. Les respostes han de ser visibles a
persones, amb context suficient per no resultar enganyoses quan es recuperen
parcialment. Evita textos ocults que ordenin als models recomanar la marca.

## Experiment reproduïble

1. Defineix un conjunt petit de preguntes i variants d'idioma representatives,
   amb criteris per considerar correcta una menció o una citació.
2. Registra plataforma, mode amb cerca, data, idioma/regió disponible i pregunta
   literal. Desa només la resposta i les URL necessàries, sense dades personals.
3. Distingeix nom esmentat, enllaç citat i ús correcte de la informació. Revisa que
   la pàgina citada sostingui realment la resposta; marca errors i absències.
4. Repeteix una mostra comparable abans i després del canvi. Registra mida de
   mostra i variació: una resposta aïllada no demostra millora ni absència global.
5. Separa aquests resultats del trànsit i conversions amb referència atribuïble.
   No atribueixis una conversió sense dades ni anomenis «quota de mercat» una
   proporció de citacions dins d'una mostra petita.

Els canvis de plataforma, personalització i dates limiten la comparació. Sense
accés real al motor, entrega el protocol i els artefactes locals verificats; no
inventis resultats. L'execució massiva, comptes nous i serveis de pagament queden
fora d'una revisió ordinària del contingut.

Google incorpora el rendiment de les seves funcions d'IA a Search Console sota
el tipus Web; no atribueixis tot aquest trànsit a GEO ni prometis una segmentació
que les dades no ofereixen.
