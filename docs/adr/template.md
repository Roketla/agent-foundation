# NNNN — Títol

- Estat: proposat
- Data: YYYY-MM-DD
- Substitueix: cap

## Context

Problema i restriccions que fan necessària la decisió.

## Opcions

Alternatives realistes i trade-offs rellevants.

## Decisió

Opció escollida i motiu. Indica qui o què valida la decisió si és necessari.

## Conseqüències i verificació

Costos, limitacions, riscos i evidència que confirmaria o faria revisar la decisió.
