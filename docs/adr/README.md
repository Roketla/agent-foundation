# Decisions d'arquitectura

Crea un ADR per a decisions costoses de revertir: stack, dades, autenticació,
multitenència, pagaments o desplegament. No en creïs per cada detall d'implementació.

Nom: `NNNN-titol-breu.md`. Context, opcions considerades, decisió, conseqüències i
com la validarem. Estat proposat/acceptat/substituït; no atribueixis una acceptació
a l'usuari si no ha succeït. Una decisió nova pot substituir l'anterior sense
reescriure'n la història. Copia `template.md`.
