# Pla de disseny — Estudi Blau

## Sistema intencional

- **Color:** Blau nit `#082B59` per a la base, blau tinta `#0B4A88` per a accions, blau cel `#C9E8FF` per als camps de respiració, blanc paper `#F8FBFF` per al fons i corall de senyal `#F15B4A` per a errors i detalls funcionals.
- **Tipografia:** `Arial Narrow`, `Helvetica Neue`, `Arial`, sans-serif per a la veu condensada de titular; `system-ui`, sans-serif per a lectura i controls. No hi ha càrregues de fonts.
- **Composició:** una pàgina vertical de dues velocitats: el titular "Estudi / Blau" ocupa l'entrada en dues línies de gran format i la resta manté una columna de lectura mesurada. Els serveis s'ordenen com a decisions de negoci, no com a targetes idèntiques.
- **Alineació:** contingut principal alineat a l'esquerra; el nom del servei i la descripció treballen en una graella que es torna una sola columna en pantalles petites.

```text
┌──────────────────────── capçalera / serveis · contacte ───────────────────────┐
│ Estudi                                                                    blau │
│ Blau             introducció curta + crida a l'acció                          │
├───────────────────────────────────────────────────────────────────────────────┤
│ Serveis          Identitat i sistema                                           │
│                  Web corporatiu                                                │
│                  Materials de proximitat                                       │
├───────────────────────────────────────────────────────────────────────────────┤
│ Contacte         formulari ──> resum local visible                              │
└───────────────────────────────────────────────────────────────────────────────┘
```

## Principis

El blau funciona com a material d'estudi: sòlid a la capçalera, lleuger als espais de treball. El gest distintiu és la paraula partida **Estudi / Blau**, una composició tipogràfica que presenta el nom sense necessitar fotografia ni decoració externa. El corall només apareix quan cal indicar un error, de manera que conserva significat.

## Revisió contra el brief

S'ha descartat l'hero de gradient, les mètriques decoratives i la quadrícula de targetes arrodonides: no aportarien informació per a una petita empresa local i podrien suggerir resultats no demostrats. La composició tipogràfica és específica del nom Estudi Blau; els serveis, el formulari local i l'avís de demostració mantenen el recorregut clar i sense promeses d'enviament.
